# QR 생성기

브라우저에서 QR을 만드는 정적 웹페이지. **https://yj0631.github.io/AI/**

## 왜 만들었나

QR은 "생성됐다"와 "읽힌다"가 다르다. 브랜드 색을 그대로 쓰면 모듈과 배경의 밝기 차이가 모자라 인식이 불안정해지는데, 화면으로는 멀쩡해 보여서 인쇄하고 나서야 알게 된다.

이 페이지는 두 색의 WCAG 대비비를 **입력하는 즉시 계산해서** 보여주고, 모자라면 색상(hue)은 유지한 채 명도만 낮춘 대안을 제시한다.

| 브랜드 색 | 흰 배경 대비 | 이 도구가 쓰는 색 |
|---|---|---|
| 네이버 `#03C75A` | 2.2 : 1 — 위험 | `#0B5E3B` |
| 유튜브 `#FF0000` | 4.0 : 1 — 적색 광원에서 뭉갬 | `#8C0B0B` |
| 카카오 `#FEE500` | 노랑은 모듈색으로 불가 | `#4A3B00` |

## 기능

- URL·텍스트 QR 생성 (입력 즉시 미리보기)
- 사이트 프리셋 18개 — 주소와 스캔 안전색이 함께 채워진다
- 색 대비 실시간 검사 + 자동 교정, 명암 뒤집힘 경고
- 오류정정 L/M/Q/H (기본 H), 여백·크기 조절
- PNG / SVG 내려받기

## 구성

```
index.html    구조
style.css     스타일 (라이트·다크 자동 전환)
app.js        생성·대비 검사·내려받기
```

빌드 도구 없음. `index.html`을 브라우저로 열면 그대로 동작한다. QR 생성은 cdnjs의 [qrcode 1.5.1](https://github.com/soldair/node-qrcode)을 쓰며, 버전을 고정해 두어 CDN 변경으로 조용히 깨지지 않게 했다.

**입력한 내용은 어디로도 전송되지 않는다.** 전부 브라우저 안에서 처리된다.

## 검증

Playwright로 페이지를 조작해 캔버스를 뽑고, OpenCV로 다시 디코딩해 원문과 일치하는지 확인했다 — 한글 포함 5건 전부 통과. 생성 성공과 스캔 가능은 다른 문제라서 눈으로만 보지 않았다.
