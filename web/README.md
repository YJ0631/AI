# 반려견 소개 페이지

지금은 **구조만 만들어 둔 상태**다. 사진과 내용은 아래 순서대로 채우면 된다. HTML·CSS·JS만 쓰며 빌드 도구가 없으므로, 파일을 고쳐 밀면 그게 곧 배포다.

## 1. 사진 넣기

`photos/` 폴더에 **정해진 이름으로** 넣기만 하면 된다. HTML을 고칠 필요가 없다.

| 파일명 | 쓰이는 곳 | 권장 |
|---|---|---|
| `hero.jpg` | 맨 위 대표 사진 | 가로 사진, 1600×900 내외 |
| `01.jpg` ~ `06.jpg` | 갤러리 | 정사각형으로 잘려 보이므로 가운데에 아이가 오게 |

사진이 없는 동안에는 그 자리에 **넣어야 할 파일명이 점선 상자로 표시된다.** 넣으면 자동으로 사진으로 바뀐다.

갤러리 칸을 늘리거나 줄이려면 `index.html`의 `<figure class="photo">` 블록을 복사하거나 지운다. `data-caption`과 `src`의 번호를 맞춰주면 된다.

### 사진 용량 줄이기

원본 사진은 보통 3~8MB라 페이지가 느려진다. 긴 변 1600px, 품질 82 정도로 줄이면 300KB 안쪽이 된다.

```bash
python -c "
from PIL import Image; import sys, pathlib
for p in pathlib.Path('photos').glob('*.jpg'):
    im = Image.open(p); im.thumbnail((1600, 1600))
    im.convert('RGB').save(p, quality=82, optimize=True)
    print(p, im.size)
"
```

## 2. 내용 바꾸기

전부 `index.html` 안에 있다. 위에서부터 순서대로:

| 위치 | 무엇 |
|---|---|
| `<title>` · `<meta description>` | 아이 이름, 한 줄 소개 |
| `.eyebrow` · `<h1>` · `.tagline` | 견종·연도, 이름, 첫인상 한 문장 |
| `.quickfacts` | 견종 / 나이 / 몸무게 / 성별 |
| `.profile` | 생일, 견종, 성별, 몸무게, 중성화, 예방접종 |
| `.traits` | 성격 태그 (5개 내외) |
| `.likes` · `.dislikes` | 좋아하는 것 / 싫어하는 것 |
| `.gallery figcaption` | 사진 설명 |
| `.stories` | 이야기 세 꼭지 |

**지금 들어 있는 "콩이"는 전부 예시다.** 그대로 두면 남의 강아지 소개가 된다.

### 글이 잘 읽히게 쓰는 법

목록만 나열하면 심심하다. 각 항목에 **그 아이만의 구체물**을 하나씩 넣는다.

- 밋밋함: "간식을 좋아한다"
- 좋음: "황태 트릿 — 이 소리에는 자다가도 일어납니다"

- 밋밋함: "훈련이 잘 되어 있다"
- 좋음: "앉아·기다려·손은 되고, ‘돌아’는 3년째 연습 중입니다"

## 3. 색 바꾸기

`style.css` 맨 위 `:root`의 값만 고친다. 아래 구조 규칙에는 색을 새로 넣지 않는다. 다크 모드는 그 아래 `@media (prefers-color-scheme: dark)`에서 **같은 토큰만** 다시 칠한다.

현재 팔레트는 따뜻한 모래빛 바탕에 데님 블루 강조다. 반려견 사이트에 흔한 크림+테라코타 조합을 일부러 피했다 — 어디서나 본 얼굴이 되기 때문이다.

## 5. 공개 저장소라는 점

이 저장소는 공개다. **올리는 순간 누구나 볼 수 있다.**

- 전화번호·주소·동물등록번호는 넣지 않는다
- 산책 코스는 "○○공원" 정도로만. 시간대까지 함께 적으면 행동 패턴이 노출된다
- 사진에 집 주소나 차량 번호가 찍혀 있지 않은지 본다
